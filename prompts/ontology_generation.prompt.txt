**Objective:** Generate a minimal ontology using OWL (Turtle syntax).


Create a semantic class hierarchy and properties using RDF/Turtle.

Use:
- owl:Class
- rdfs:subClassOf
- owl:ObjectProperty or owl:DatatypeProperty

Format:
@prefix : <http://example.org/ontology#> .

:Neuron rdf:type owl:Class .
:MotorNeuron rdf:type owl:Class ;
             rdfs:subClassOf :Neuron .

:transmitsSignal rdf:type owl:ObjectProperty ;
                 rdfs:domain :Neuron ;
                 rdfs:range :Signal .
